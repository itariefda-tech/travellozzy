# TRAVELOZZY — BLUEPRINT

## 1. Document Purpose

Dokumen ini adalah blueprint utama untuk desain, UX, content strategy, dan struktur landing page website **TRAVELOZZY**.

Blueprint ini menjadi sumber acuan utama untuk:

- arah visual brand;
- struktur landing page;
- responsive behavior desktop vs mobile;
- hierarchy informasi;
- layanan utama;
- segmentasi armada;
- paket layanan;
- booking flow;
- CTA;
- component behavior;
- content shortening;
- interaction pattern;
- color palette;
- typography;
- animation;
- conversion strategy;
- SEO page expansion.

Dokumen ini **bukan roadmap implementasi**. Progress development akan dikelola terpisah di `ROADMAP.md`.

---

# 2. Brand Definition

## Brand Name

**TRAVELOZZY**

## Main Tagline

> **Drive Your Moment.**

## Supporting Line

> **From everyday rides to extraordinary moments.**

## Brand Positioning

TRAVELOZZY tidak diposisikan hanya sebagai rental mobil.

TRAVELOZZY adalah:

> **Mobility & Travel Service**

yang menyediakan kendaraan reguler hingga luxury untuk kebutuhan:

- harian;
- event;
- vacation;
- airport transfer;
- perjalanan bisnis;
- perjalanan VIP;
- wedding;
- perjalanan keluarga;
- perjalanan luar kota;
- transportasi rombongan.

Positioning utama:

> **Affordable Premium**

Artinya TRAVELOZZY:

- tidak tampil sebagai rental murah;
- tetap menyediakan kendaraan reguler;
- mempunyai kelas premium dan luxury;
- profesional tanpa terasa terlalu kaku;
- modern dan mudah digunakan;
- relevan untuk individual, keluarga, event, dan corporate.

Prinsip inti:

> **TRAVELOZZY tidak hanya menjual mobil. TRAVELOZZY menjual solusi perjalanan.**

Customer biasanya tidak datang dengan pikiran:

> “Saya ingin Toyota Zenix.”

Customer lebih sering datang dengan kebutuhan:

> “Besok keluarga saya mau ke Bandung.”

> “Saya harus menjemput direktur di bandara.”

> “Saya membutuhkan mobil untuk wedding.”

> “Saya perlu kendaraan harian.”

Website harus mengikuti **cara customer berpikir**, bukan cara rental menyusun garasi.

# 24. Desktop vs Mobile Philosophy

## Desktop

Flow:

> **Explore → Understand → Compare → Book**

Desktop boleh lebih kaya:

- narasi;
- detail;
- photography besar;
- storytelling;
- fleet comparison;
- benefit;
- destination showcase;
- testimonial.

## Mobile

Flow:

> **See → Choose → Book**

Mobile harus lebih ringkas:

- kebutuhan;
- kendaraan;
- paket;
- CTA;
- WhatsApp;
- detail hanya bila diminta.

Prinsip utama:

> **Desktop menjelaskan. Mobile mengarahkan.**

# 62. Animation

Allowed:

- fade-up;
- image reveal;
- subtle hover;
- horizontal slide;
- number counter;
- smooth scrolling;
- soft card movement.

Avoid:

- excessive parallax;
- spinning elements;
- over-animated text;
- moving car gimmick.

Premium experience harus terasa:

> tenang.

- AVIF / WebP;
